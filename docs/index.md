# QueryFilter

Declarative query filtering for CakePHP index actions.

Map form input keys to table finders and apply them to a query in a single
call. Each finder turns the submitted value into query conditions, so
controllers stay free of filter plumbing.

- [Templates](templates.md) — building field/value conditions.
